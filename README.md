# SolidityDev

SolidityDev streamlines Auto-Scaling and Real-Time Data Processing for Optimized Smart Contract Execution and Real-Time Monitor Analysis on Console.

SolidityDev is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityDev.git`
2. `cd SolidityDev`
3. Install in editable mode: `pip install -e .`

## Configuration

SolidityDev is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
